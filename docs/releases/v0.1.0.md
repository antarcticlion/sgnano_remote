# sgnano_remote v0.1.0

`sgnano_remote` の最初のリリースです。

sgnano は、Raspberry Pi RP2350B を使った自作のビデオコンソールです。`sgnano_remote` は、PC と sgnano を UART（シリアルポート）でつなぎ、PC 側と sgnano 側のファイルを 2 画面で管理するデスクトップアプリです。

## 主な機能

- PC と sgnano の 2 画面ファイル管理
- シリアルポート接続（既定 921600 baud）
- ドライブ一覧、フォルダ一覧、移動
- ファイルのアップロード・ダウンロード
  - アプリ内蔵の ZMODEM を使用
  - `lrzsz`、Python、外部スクリプトは不要
- 新しいフォルダ、名前の変更、削除
- 複数選択の削除（8 件ずつ順に送信）
- リモート内のコピー
- リモート内の分割・結合（`.001`、`.002` …）
- S:（内蔵フラッシュ 4 MB、FAT12）に対応
  - `SystemSettings`、`SystemFiles`、`SystemLogs` は保護
- S: の FAT12 検査・修復（SYSFSCK）
- 4 MB 超のダウンロード（sgnano が送りながら読み出すストリーミング）
- 4 MB 超のアップロード（PC 側で分割し、sgnano の JOIN で結合）
- Windows 10/11 x64 用の per-user NSIS インストーラ
- Linux 向けのソースビルド
- 角丸の黄色い五芒星アイコン

## 動作環境

### sgnano 側

- sgnano 本体（RP2350B）
- 遠隔コマンドに対応したファームウェア
- UART（Raspberry Pi Debug Probe など）
- sgnano がファイラー画面を表示していること

### PC 側

- Windows 10/11 x64
- または Linux（Qt 6.2 以降）

## インストール

### Windows

`sgnano_remote_setup_0.1.0.exe` を実行してください。

- 管理者権限は不要です（per-user インストール）。
- インストール先の既定:
  ```
  %LOCALAPPDATA%\Programs\sgnano_remote
  ```
- スタートメニューとデスクトップにショートカットを作成します。

> **注意**
>
> このインストーラはコード署名をしていません。Windows SmartScreen の警告が表示されることがあります。
> 内容を確認したうえで「詳細情報」→「実行」を選んでください。

### Linux

ソースコードからビルドしてください。

```bash
sudo apt install build-essential cmake ninja-build qt6-base-dev
cmake -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build
./build/sgnano_remote
```

## 使い方

1. sgnano をファイラー画面にします。
2. PC と sgnano を UART でつなぎます。
3. `sgnano_remote` を起動します。
4. シリアルポートを選び、ボーレートを 921600 にします。
5. 「接続」を押します。
6. 左側が PC、右側が sgnano のファイル一覧です。

アップロードは左側のファイルを選んで「アップロード」、ダウンロードは右側のファイルを選んで「ダウンロード」です。
右側の右クリックメニューから、フォルダ作成・名前変更・削除・コピー・分割・結合・S: の検査ができます。

## 実機で確認したこと

- Windows 10/11 x64、COM ポート経由
  - 接続、ドライブ一覧、フォルダ一覧
  - S: の SYSFSCK（検査）
  - exFAT の MKDIR / REN / DEL
  - 4 MB + 123 バイトの分割アップロード → JOIN → ダウンロード
  - 64 KB の COPY / SPLIT / JOIN
- Linux、`/dev/ttyACM0` 経由
  - 上記に相当する実機テスト
  - exFAT への 34 フォルダの作成と一括削除

## 既知の制限

- ZMODEM の 1 ファイルの上限は 4 MB です。
- sgnano の JOIN は 64 個までです。
- 64 MB を越えるファイルは、sgnano 側のメモリ不足や制限で失敗することがあります。
- 現在、500 MB 程度の単一ファイルをこの経路で送ることはできません。
  - 大きなファイルは、USB メモリ／USB-HDD にコピーして sgnano に接続する方法をおすすめします。
- 同一 exFAT 内の 4 MB 級のコピーは、sgnano 本体側の read error で失敗することがあります。
- NTFS への対応は実装していますが、手元の実機に NTFS 区画が無いため、NTFS での実機試験は未実施です。
- Windows インストーラは未署名です。
- sgnano のプログラム（Doom・Ruby・Python など）が動いている間は、遠隔コマンドが拒否されることがあります。ファイラー画面に戻ってから操作してください。
